## 三、项目经历

### 1. 雪穗博客（Yuki Blog）· 已上线
- **定位**：基于 Astro 7 + Firefly 主题二次开发的静态博客，Cloudflare Pages 托管，**推送 `master` 即自动构建上线**。
- **技术栈**：Astro 7 / Svelte / TypeScript / Tailwind / Pagefind。
- **核心贡献**：
  - 班级**动态课表**：按周次自动推算当前周、支持换教室/调课/对调/停课/新增/提示六种调整，数据驱动。
  - 教材书单、新生组队匹配、站点统计等班级事务与运维页面。
  - 文章系列、项目展示、待办清单等交互组件；长期维护主题升级与线上 bug 修复。

### 2. Yuki-Blog App（Flutter 班级应用）· 开发中
- **定位**：给班级写的 Flutter 应用，一套代码跑 Android / iOS / macOS / Windows / Web，核心模块为**动态课程表**（与博客课表数据同源同步，改一次 JSON 两端自动更新，无需发版）。
- **技术栈**：Flutter 3 + Dart / go_router / Material 3 / GitHub Actions。
- **核心贡献**：
  - 周次自动推算、六种调课类型、课程详情、本周调整面板、通知区与数据更新历。
  - **光感沉浸标题栏**：复刻博客导航栏的渐进模糊配方，自研分带 `BackdropFilter` 实现，封装为公共组件，四端无平台分支。
  - **应用内更新**：GitHub Releases 语义化版本比对 + 流式下载（进度/速度/取消）+ 唤起系统安装器；CI 自动构建签名 APK，固定发版签名保证覆盖安装。
  - **离线优先数据同步**：线上站点 / GitHub raw / jsDelivr 三源回退，全失败回退打包资源。

### 3. Yuki Agent（Python Agent 内核）· 开发中
- **定位**：可嵌入的 agent 运行时，分「空白大脑」内核 `yuki-kernel` 与示例聊天外壳 `yuki`。
- **技术栈**：Python / OpenAI + Anthropic Provider / 契约测试。
- **核心模块**：事件总线、记忆、上下文组装、策略与审批、模型接入、技能与工具。
- **关键能力**：会话管理（`/save`、`/load`、`/sessions`）、外置工具包热加载（`/pkg install`）、Provider 可切换。

### 4. EduSync · 学校多媒体设备互联系统 · 已归档
- **定位**：面向学校多媒体设备（老式 Windows 台式机、希沃一体机）的中心化互联系统。
- **技术栈**：Vue 3（前台）/ Python（服务端）。
- **核心功能**：设备实时运行状况检测与上报、服务端远程介入终端（如下发停止进程指令）、教育资源多端一键共享。
- **关联荣誉**：该系统即 2025 粤港澳学生信息科技创新大赛**二等奖**获奖作品《学校多媒体设备互联系统》。

### 5. fsp · AI 自主学习系统 · 竞赛 / 在研
